# Spec: Product Details View

## Goal
Display comprehensive information about a specific product selected by the user.

## Behavior
- Display product title, price, and description.
- Show an image gallery of the product.
- Allow the user to select a product quantity.
- "Add to Cart" button should be prominent.
- Handle "not found" state gracefully.

## Constraints
- Must be accessible (correct heading structure, alt text for images).
- Must load quickly (show skeleton while loading).
